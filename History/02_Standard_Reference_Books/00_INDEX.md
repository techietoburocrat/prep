# 📚 History — Standard Reference Books
## What each book is for, and the boundary between them

> ⭐⭐⭐⭐⭐ **The whole method in one line:** *your NCERT notes (Classes 6–12, ~60,000 lines) are the **spine**. **Every book in this folder is written as a DELTA over that spine** — each file opens with a "what you already have" table and covers **only the increment**. **Nothing gets summarised twice.**

## 5️⃣ 📐 The shared file template

**Identical to the NCERT chapter notes**, so the two bodies of work read as one:

```
   \U0001f4ce  WHAT YOU ALREADY HAVE  -- table with links + a
                                DELTA SIZE badge
   \U0001f3f7️  Syllabus classification
   \U0001f3af  Learning outcomes
   1️⃣ ..  the increment only
   ⚡  UPSC Focus -- \U0001f534 Prelims traps + \U0001f7e2 Mains angles
   \U0001f511  Glossary   \U0001f501  Recap   ✍️  Practice questions
```

⭐ **The 🔴 Prelims-traps tables double as the raw material for the Class XI–XII quiz banks** — they are already *claim vs truth* pairs, which is the shape of an MCQ.

⚠️ **Verification rule:** anything **list-shaped or datable** *(Acts, session years, dynasty dates, UNESCO counts, GI tags)* is **cross-checked against a second source** before it goes into a table, and anything unconfirmed is tagged ⚠️`[VERIFY]` rather than asserted — the same discipline as Geography's volatile-figure register.
