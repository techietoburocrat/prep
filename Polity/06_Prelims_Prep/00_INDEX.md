# 06 · Prelims Prep — Chapter-wise Practice Sets

> **What this folder is.** For every chapter you finish, there are **10 practice sets × 25 questions = 250 questions**, written at real UPSC Prelims pattern and difficulty.
>
> **What it is for.** Not scoring. *Concept clarity.* Every explanation tells you why the right option is right **and why each wrong option is wrong** — that second half is where the learning happens.

## The formats drilled

Real Prelims since 2023 leans on formats that defeat elimination. All of them appear here in realistic proportions:

- Direct single-correct
- *"Consider the following statements… which is/are correct"* (code options)
- *"How many of the above are correct?"* — Only one / Only two / All three / None
- **Statement-I / Statement-II** assertion-reason
- Match-the-pairs, in counting form
- Chronological ordering
- *"Which one of the following best describes…"* — conceptual, no date to recall

**Answer keys are balanced** (~25% each across a/b/c/d) so you cannot pattern-guess your way through a set.

## How to use these sets

**After finishing a chapter (first pass)**
1. Read the chapter notes → wait 1 day → attempt **Sets 1–3** (foundation).
2. Same week → **Sets 4–7** (topic-wise, exam standard).
3. Before moving to the next chapter → **Sets 8–10** (full-chapter mixed, hardest).

**For revision (2nd / 3rd pass)**
- Straight to **Sets 8, 9, 10**. If you score below 60% there, go back and redo 4–7.

**Rules while attempting**
- Timer on. 25 questions in **30 minutes**. No notes, no pausing.
- Mark every question you guessed, even if you got it right. Those are your real weak points.
- Score with the real scheme: **+2 correct, −0.66 wrong, 0 unattempted.**
- Then read **every** explanation — including the ones you got right.
