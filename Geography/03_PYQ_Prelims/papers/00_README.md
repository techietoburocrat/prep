## ⚠️ Why the keys still aren't filled in yet

**Two obstacles, both mechanical:**

1. **Every one of these files is a scanned image with no text layer.** `pdftotext` returns zero characters from all twelve. They have to be read visually, page by page — they cannot be parsed by script.
2. **UPSC keys are numbered by booklet set (A/B/C/D), and the compilation our year files came from renumbers everything as Q1, Q2, Q3…** So a key row cannot be matched to a question by position. The question's **original UPSC number** has to be recovered from the official paper first, then looked up in the key.

**That means the work is:** read each paper, find the geography questions by their text, note the real question number, read that row of the key. It is slow but it is exact — and it is the only method that cannot install a wrong answer.
