Class 6 — Social and Political Life I
======================================
NCERT has removed this book's ZIP from their server (NEP 2020 revision).

HOW TO GET IT:
Option 1 — DIKSHA App (Best):
  Install the DIKSHA app (gov.in official).
  Search: "Social and Political Life Class 6"
  Download for offline reading.

Option 2 — NCERT Website:
  Go to: https://ncert.nic.in/textbook.php?fess3=0-10
  Select Class 6 > Social Science > Social and Political Life I
  Download chapter by chapter.

Option 3 — ePathshala:
  Website: https://epathshala.nic.in
  OR install the ePathshala app.
  All NCERT books available offline.

FOR UPSC: This book is LOW PRIORITY.
- It covers very basics (what is diversity, local government, urban admin)
- Class 8 and Class 11 books cover these topics more deeply
- Skip this if time is short. Read Class 8, 9, 10, 11, 12 first.
