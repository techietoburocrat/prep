# 🗓️ MASTER SCHEDULE — UPSC CSE 2027

**Runway:** today is 2026-08-02. Prelims is ~May 2027. That's **~9-10 months, ~40 weeks**.
**Budget:** ~4 hrs/day average (ranges 3-5), no separate weekend bump — treat as flat across the week.
**This is a living document.** Week counts below are estimates, not deadlines. Update "Where things actually stand" as sessions happen, and re-derive the rest from there — don't force reality to match the original guess.

## The three phases

| Phase | Window | Goal |
|---|---|---|
| **A — Foundation** | Aug 2026 → Jan 2027 (~6 mo) | One solid pass through every static subject. Breadth + PYQ pattern, not Mains-depth. |
| **B — Integration** | Feb → Mar 2027 (~2 mo) | Layer current affairs onto the static base. Start sectional/full-length tests. |
| **C — Revision + Mocks** | Apr → May 2027 (~6-8 wk) | No new topics. Full-syllabus revision, 2-3 mocks/week, error log only. |

## Subject rotation order (Phase A)

Order follows Prelims weightage + what's already ahead of schedule:

1. ✅ **Polity** — largely done (Laxmikanth Part I, NCERT Cl.6-11, 147 Prelims PYQs, 299 Mains PYQs). Remaining: Laxmikanth Part II, NCERT Class 12 notes, Prelims 2024-26 PYQs. Small lift, fold in whenever there's a short gap — doesn't need a dedicated block.
2. 🔵 **History** — starting now. Modern India → Art & Culture → Indian Society → Medieval → Ancient → World History, per the weightage discussion.
3. 🔵 **Geography + Environment (merged)** — started 8 Aug 2026, **merged into one subject 9 Aug** because the boundary between them is arbitrary and splitting them meant studying monsoons, soils and biomes twice. Physical geography first (Cl.11 *Fundamentals* + G.C. Leong, interleaved), each topic closed from both the geography *and* environment side in the same sitting. Daily 15-min map habit from day 1. **~240 hrs / ~12-13 weeks** — the largest Phase A block, but it returns **~60 Prelims marks**, the biggest cluster in the paper. See [Geography/00_START_HERE.md](Geography/00_START_HERE.md).
4. ⬜ **Economy** — not started.
5. ~~Environment & Ecology~~ → **folded into #3.** No longer a separate block.
6. ⬜ **Science & Tech** — not started.
7. ⬜ **CSAT** — not started, but lower priority *by design*: it's qualifying-only (33% to clear) and quant/logic-heavy, which plays to a software engineer's existing strength. One practice set a month from ~Nov 2026 onward is enough — no dedicated block needed unless a diagnostic test says otherwise.

By end of Phase A (~Jan 2027), every subject above should have had one full pass.
