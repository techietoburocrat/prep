# 📚 02_THEMES — the real revision material

**This is the folder you will actually revise from.** `01_Daily/` is a scratchpad; these eight files are where the week's items go to become permanent.

Organised by **syllabus topic, not by date** — because in April 2027 you will want to revise "everything that happened in Environment," never "everything that happened in the second week of October."

## The entry format

Every item is **one table row**. Resist the urge to write paragraphs — a row you'll re-read beats an essay you won't.

```markdown
| Date | Item | Why it's asked | Static hook | ⭐ |
|---|---|---|---|---|
| 04 Aug | Governor returned state bill without assent | No time limit under Art. 200; "as soon as possible" is directory | Laxmikanth — State Legislature | |
```

- **Item** — one line, factual, no adjectives
- **Why it's asked** — *the testable thing.* This column is the whole point of the folder. If you can't fill it, the item doesn't belong here
- **Static hook** — chapter/article. `❓` if you don't know it yet — that's a syllabus hole, and it's useful information
- **⭐** — put a star here when you get this wrong in a quiz. **Starred rows are your real syllabus**

Below the table, each file has a **Deep dives** section for the 2–3 running stories per theme that genuinely need a paragraph.

---

## The one rule that keeps this folder alive

**Nothing enters these files except on Sunday.** Not mid-week, not "quickly while I remember." Batching the filing is what makes it a 45-minute job instead of a constant tax — and the week's delay is a free relevance filter, because a third of what felt important on Tuesday is obviously noise by Sunday.
