## The tiering rule

| Tier | Test |
|---|---|
| 🔴 **1** | A Prelims question could be built on it *as it stands*, or it's a scheme/body/judgment with named specifics. Revised again in Phase C |
| 🟠 **2** | Real syllabus relevance but unlikely to be asked directly — context, or Mains-only material |
| 🟡 **3** | Appears in compilations, almost certainly won't be asked. Recorded so coverage is complete and skipping is a *decision*, not an accident |

**When unsure, go lower.** Tier inflation is the failure mode — if everything is Tier 1, nothing is.
